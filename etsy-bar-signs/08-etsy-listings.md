# Etsy Listing Copy — Wave 1

Title, tags, and description for each sign. Optimized for Etsy search.

**Etsy rules baked in:**
- **Title:** 140 characters max, first 40 chars matter most (search weight + mobile truncation)
- **Tags:** 13 tags max, each up to 20 chars, all lowercase, multi-word tags are fine (and often stronger)
- **Description:** First 160 chars show above the fold on mobile — hook hard
- **Attributes** (category, material, color, orientation, room, occasion) drive filtering — fill them all
